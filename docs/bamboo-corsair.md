# The Bamboo Corsair

A night voyage in violet sails, bamboo green, and ghost lantern mint, based on
the supplied panda pirate illustration. The original artwork is preserved as
`wallpaper/bamboo-corsair.png` and fills the desktop with aspect ratio preserved.

| Role | Color |
| --- | --- |
| Midnight background | `#100c20` |
| Violet sail surface | `#211531` |
| Pale mint text | `#d9efcf` |
| Bamboo green / focus | `#91e66d` |
| Lantern mint | `#76cda8` |
| Sail lavender | `#a57ace` |
| Coral alerts | `#ef8198` |

Includes AwesomeWM, Kitty, Alacritty, LXTerminal, tmux, Rofi, Picom, Starship,
btop, Neovim, and Python pads. Unfocused application windows use 76% opacity
with gentle blur; focused windows use 100%. Docks and the wallpaper are excluded
from the inactive window rule. Kitty and Alacritty use opaque backgrounds so
Picom controls the focus transition without compounding transparency.

Select `theme-toggle bamboo-corsair` (aliases: `bamboo`, `corsair`,
`the-bamboo-corsair`). Installing the theme does not change the active desktop.
