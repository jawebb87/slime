# Mothgomery — Lamplit Workshop

Mothgomery is Baron von Gill's companion: the same 36px flat bar, rounded glass
pods, 7px gaps, JetBrains Mono type, launcher stamp, and mascot console, warmed
by the moth inventor's brass, copper, and parchment palette.

The supplied artwork is preserved at `wallpaper/mothgomery.png`. A small vector
mascot keeps the goggles, monocle, feathered antennae, and patterned wings legible
at bar height.

| Role | Color |
| --- | --- |
| Cavern background | `#0d1c21` |
| Glass surface | `#142a30` |
| Parchment text | `#efdfbf` |
| Brass focus | `#e8bb76` |
| Lamp glow | `#f3d395` |
| Copper alert | `#df9774` |
| Fungal teal | `#75c9c7` |

Includes AwesomeWM, Kitty, Alacritty, LXTerminal, tmux, Rofi, Picom, Starship,
btop, and Python pad colors. Click the MOTH stamp for the launcher; click the
mascot or press F12 for the persistent Mothgomery console.

After deploying the repository configuration, select `theme-toggle mothgomery`.
Aliases: `moth`, `workshop`, `lamplight`. This addition does not activate the theme.
