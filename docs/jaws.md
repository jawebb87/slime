# Grindhouse JAWS

A dark midnight-ocean theme based on the supplied grindhouse poster. The original
1024 × 572 artwork is preserved in `wallpaper/jaws.png`; desktop fill may crop its
edges to match the screen aspect ratio.

| Role | Color |
| --- | --- |
| Ocean background | `#0b151b` |
| Panel surface | `#14252d` |
| Aged cream text | `#ecdfbf` |
| Poster yellow / focus | `#e8bd4e` |
| Blood red / alerts | `#ef7160` |
| Sea mist | `#7db4ba` |

Includes AwesomeWM with a JAWS launcher stamp, Kitty, Alacritty, LXTerminal,
tmux, Rofi, Picom, Starship, btop, Neovim, and Python pads. Dark GTK preference
is selected by the existing theme switcher.

Select `theme-toggle jaws`; aliases are `grindhouse`, `grindhouse-jaws`, and
`shark`. Installation does not switch the active theme.
